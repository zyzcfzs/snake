# Snake Arcade

Open index.html in a browser to play. Use the arrow keys, WASD, or the on-screen controls. Space pauses or resumes the game. Eat food to grow and score. Hitting the wall or your own body ends the run. Your best score is saved in the browser when local storage is available.

## Deploy on GitHub Pages

1. Extract the ZIP and commit its contents to the root of your GitHub repository. Keep index.html, style.css, game.js, and .nojekyll together.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose your branch and **/(root)**, then save.
4. When GitHub finishes deploying, open the site from the Pages settings.

All asset paths are relative. The project works under a GitHub Pages repository path and requires zero dependencies or build commands.
